Kinematics is the grammar of mechanics. These notes compress every result you need before solving HC Verma / PYQ sets.

## Core equations (constant acceleration)

```formula:First equation
v = u + at
```

```formula:Second equation
s = ut + ½at²
```

```formula:Third equation
v² = u² + 2as
```

## Projectile motion

```formula:Range
R = u²sin2θ / g
```

```formula:Max height
H = u²sin²θ / 2g
```

> [!TIP] JEE loves relative-motion frames and graphs. Convert every word problem into a velocity-time graph first.

```keys
- Range is maximum at 45°; symmetric angles give equal range.
- Relative velocity: v_AB = v_A − v_B (vector).
- River-boat and rain-man are the two classic relative-motion frames.
```
