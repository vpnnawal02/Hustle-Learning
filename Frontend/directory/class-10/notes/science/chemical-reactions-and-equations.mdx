## Balanced chemical equations

A chemical equation lists reactants on the left and products on the right. Coefficients are adjusted so that the number of atoms of every element is equal on both sides, satisfying the law of conservation of mass.

## Types of reactions

| Type | Pattern | Example |
| ---- | ------- | ------- |
| Combination | A + B → AB | CaO + H₂O → Ca(OH)₂ |
| Decomposition | AB → A + B | CaCO₃ → CaO + CO₂ |
| Displacement | A + BC → AC + B | Fe + CuSO₄ → FeSO₄ + Cu |
| Double displacement | AB + CD → AD + CB | Na₂SO₄ + BaCl₂ → BaSO₄ + 2NaCl |

## Frequently asked questions

Q: How do I balance equations quickly?

A: Start with the compound containing the most atoms, balance metals first, then non-metals, and hydrogen/oxygen last. Recheck every element at the end.
