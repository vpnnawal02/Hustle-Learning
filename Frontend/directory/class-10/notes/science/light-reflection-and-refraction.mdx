Light chapters reward diagram practice. Learn the rules, then draw every standard ray diagram at least twice.

## Reflection

Concave mirrors converge light; convex mirrors diverge it. The mirror formula 1/f = 1/v + 1/u uses the Cartesian sign convention: distances measured against incident light are negative.

## Refraction

Light bends when it enters a medium of different optical density. Refractive index n = speed of light in vacuum / speed in medium. Lenses follow 1/f = 1/v − 1/u with the same sign convention.

```formula:Mirror formula
1/f = 1/v + 1/u
```

```formula:Lens formula
1/f = 1/v − 1/u
```

## Frequently asked questions

Q: Which diagrams should I practise?

A: Object at C, F and between F and P for concave mirrors; object at infinity and between infinity and optical centre for convex lenses.
