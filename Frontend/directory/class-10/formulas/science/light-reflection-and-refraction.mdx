Quick-revision sheet for the Physics chapters of Class 10 Science. Keep it with your admit card in exam week.

## Light

```formula:Mirror formula
1/f = 1/v + 1/u
```

```formula:Lens formula
1/f = 1/v − 1/u
```

```formula:Magnification
m = h′/h = −v/u (mirrors), m = v/u (lenses)
```

## Electricity

```formula:Ohm's law
V = IR
```

```formula:Resistors in series
R = R₁ + R₂ + R₃
```

```formula:Resistors in parallel
1/R = 1/R₁ + 1/R₂ + 1/R₃
```

```formula:Electric power
P = VI = I²R = V²/R
```
